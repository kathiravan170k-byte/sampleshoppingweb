# 🛍️ Sample Shopping Website

This is a simple **shopping website mini project** created using HTML.

I developed this project while learning HTML from the **Balachandra HTML YouTube tutorial**. The main purpose of this project is to practice HTML concepts by building a basic shopping website.

## 📌 About the Project

The website represents a simple online shopping platform where users can:

- View the home page
- Browse different products
- View product information
- Contact the website
- Read the Terms & Conditions
- Navigate between different pages

## 🛠️ Technologies Used

- HTML5
- Basic HTML Forms
- HTML Links
- HTML Tables
- HTML Images

> CSS and JavaScript can be added in future versions to improve the design and functionality.

## 📂 Project Structure

```text
SampleShoppingWeb/
│
├── index.html
├── products.html
├── contact.html
├── T&C.html
│
├── images/
│   └── Product Images
│
└── README.md
```

## 📄 Pages

### 🏠 Home Page
The home page introduces the shopping website and provides navigation to other sections.

### 🛒 Products Page
Displays the products available on the website along with their details.

### 📞 Contact Page
Provides a form and information for users to contact the website.

### 📜 Terms & Conditions
Contains the basic terms and conditions for using the shopping website.

The main objective of this project is to:
